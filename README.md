# 🔐 Password Cracking Lab – Networkwalks

## 📌 About This Task

As part of my Networkwalks cybersecurity internship, I worked on a basic **password cracking lab**.

In this task, I learned how password hashes are used and how password-cracking tools can be used in a controlled lab environment.

For the practical, I used a **password-protected PDF provided by the instructor** and tested it using John the Ripper. I also used the password hash and password-cracking tools provided on the Networkwalks website.

---

## 🎯 Objective

The main objective of this task was to understand:

* What a password hash is
* How a password-protected PDF can be tested
* How John the Ripper works
* How password-cracking tools work
* How weak passwords can be recovered during testing
* Why strong passwords are important

---

## 🛠️ Tools Used

* **Kali Linux**
* **John the Ripper**
* **Networkwalks Hash Generator**
* **Networkwalks Password Cracker**
* **Password-protected PDF provided by the instructor**

---

## 🔹 Part 1 – Password-Protected PDF

The instructor provided us with a **locked PDF file** for the password-cracking activity.

I used this PDF for the practical instead of creating my own file.


---

## 🔹 Part 2 – Using John the Ripper

I used **John the Ripper** in Kali Linux to test the password of the provided PDF.

At first, I was confused because I tried to work with the PDF directly. Later, I understood that the password information needed to be extracted into a suitable format before John could work with it.

After correcting this, I started the password-cracking process.

---
## ⚠️ Problem I Faced

At first, John the Ripper did not crack the password.

I thought there was a problem with the tool, but after checking again, I understood that the issue was with the way I was doing the process.

I also tested a password containing:

* Uppercase letters
* Lowercase letters
* Numbers
* Special characters

This took longer and was not recovered immediately.

This helped me understand that password complexity can make password cracking more difficult.

---

## 🔹 Part 3 – Networkwalks Hash Generator

I also used the **Hash Generator provided on the Networkwalks website**.

I entered the required test password and generated its hash.


---

## 🔹 Part 4 – Networkwalks Password Cracker

After generating the hash, I used the **Networkwalks Password Cracker** provided for the activity.

I entered the required information and started the cracking test.

This helped me understand the basic process:

**Password → Hash → Cracking Attempt → Recovered Password**



---

## ❌ Mistakes I Made

I made some basic mistakes while doing this task.

* At first, I tried to use the PDF directly with John.
* I was confused about the difference between the PDF and the extracted hash.
* I thought John was not working when the password was simply not being recovered.
* I expected a complex password to be cracked quickly.

After checking the process again, I understood where I was going wrong.

---

## 📚 What I Learned

From this task, I learned:

* A password and its hash are not the same thing.
* Password-cracking tools cannot automatically crack every password.
* The result depends on factors such as password complexity and the passwords being tested.
* Weak passwords can be easier to recover.
* Longer and stronger passwords provide better protection.
* John the Ripper can be used for password auditing in a controlled environment.
* Practical testing helped me understand password security better.
